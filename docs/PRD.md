# 灵犀创作 · 产品需求文档（PRD）

> 版本：v1.0 ｜ 日期：2026-09-22 ｜ 状态：本版交付实现

## 1. 产品定位

**灵犀创作**是一款面向中文网络文学作者的 **AI 辅助小说创作平台**。作者在平台内完成从「灵感 → 大纲 → 设定 → 正文」的全流程写作，AI 作为"创作搭子"贯穿始终：生成全书大纲、续写正文、润色文本、扩写细节、头脑风暴答疑。

Slogan：**让灵感，落笔成章。**

## 2. 目标用户与痛点

| 用户画像 | 痛点 | 平台解法 |
| --- | --- | --- |
| 网文新人作者 | 不知如何开书、大纲难写、开篇容易卡文 | AI 一键生成全书大纲与章节大纲，卡文时 AI 续写 |
| 兼职更新作者 | 日更压力大、文字平淡 | AI 续写保底产出，AI 润色/扩写提升文本质量 |
| 有想法缺表达的写手 | 人物设定、世界观写得干瘪 | 结构化的角色/世界观设定库 + AI 头脑风暴 |

## 3. 核心用户旅程

```
注册登录 → 新建作品（书名/类型/简介）→ AI 生成全书大纲 → 沉淀角色与世界观设定
        → 逐章写作（AI 续写 / 润色 / 扩写）→ 积累字数与章节 → 完结
```

## 4. 功能清单

### P0（本版交付）

| 模块 | 功能点 | 说明 |
| --- | --- | --- |
| 账户 | 注册 / 登录 / 退出 | 用户名 + 密码，JWT 会话，BCrypt 加密存储 |
| 作品管理 | 新建 / 编辑 / 删除 / 列表 | 书名、类型、简介、目标字数、状态（草稿/连载中/已完结），卡片墙展示，统计总字数/章节数 |
| 章节管理 | 新建 / 编辑 / 删除 / 列表 | 章节序号、正文编辑器（自动保存 + Ctrl+S），字数实时统计 |
| 设定库 | 角色设定 / 世界观设定 | 每本书独立维护，角色含姓名/定位/描述，世界观含条目标题/内容 |
| 全书大纲 | 编辑 + AI 生成 | 每本书一份大纲文本，AI 流式生成后可一键应用 |
| AI 写作 | 续写 | 基于全书设定 + 上一章结尾 + 当前章已有内容，从光标处/文末流式续写 |
| AI 写作 | 润色 / 扩写 | 对选中文本流式改写，确认后替换所选内容 |
| AI 助手 | 对话式头脑风暴 | 结合作品上下文的多轮对话（剧情讨论、卡文求助、人设打磨） |
| AI 输出 | 流式 + 可控 | 所有 AI 输出走 SSE 流式（打字机效果），可中途停止，插入前先预览 |

### P1（后续迭代，本期不做）

多人协作/共享、版本历史与回滚、AI 生成章节细纲并批量建章、发布到书城、Prompt 模板市场、语音口述写作。

## 5. 关键页面

1. **登录/注册页**：左侧品牌区（渐变视觉 + 卖点），右侧登录/注册双 Tab。
2. **作品台（首页）**：统计卡片（作品数/总字数/总章节）+ 作品卡片墙 + 新建作品弹窗。
3. **作品详情页**：Tabs —— 章节 / 角色 / 世界观 / 大纲 / AI 助手。
4. **写作页**：沉浸式正文编辑器（宋体、双倍行距、820px 版心），顶部章节名/字数/保存状态/AI 工具栏，右侧 AI 输出抽屉。

## 6. AI 能力设计

- **上下文构建**：书名、类型、简介、全书大纲、角色设定、世界观、上一章结尾（≤1500 字）、当前章已有内容，统一注入系统提示词，保证"AI 懂这本书"。
- **任务类型**：全书大纲 / 续写 / 润色 / 扩写 / 对话。
- **输出方式**：服务端 SSE 流式返回，前端打字机渲染；完成后用户手动选择"插入光标处 / 追加到文末 / 替换所选"，AI 不直接改写正文，避免覆盖用户内容。
- **供应商解耦**：后端对接 OpenAI 兼容协议（可配 DeepSeek/通义/Kimi 等），`lingxi.ai.provider=mock` 时内置离线示例引擎，无 API Key 也可完整体验全流程。

## 7. 非功能需求

- 安全：密码 BCrypt；接口 JWT 鉴权；所有作品数据按用户隔离（越权访问返回 404）。
- 性能：常规接口 < 300ms；AI 首字延迟取决于上游模型，SSE 全程流式。
- 可靠：正文自动保存（防抖 3s）；AI 异常以 error 事件透出且不影响正文数据。
- 兼容：Chrome/Edge 最新版，宽度 ≥ 1200px 桌面端优先。
