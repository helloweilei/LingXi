## 生成正文支持「作者有话说」（作者干预）
- 需求：生成正文弹框增加「作者有话说」输入字段，让用户对创作内容加以干涉。
- 后端：
  - `AiController.WriteReq` 增加 `authorNote` 字段；`/write` 与 `/write-continue` 透传。
  - `AiService.writeChapterAndSave` 增加带 `authorNote` 的重载（原 5 参重载保留，AutoWriteService 不受影响，传 null）。
  - `AiService.writeChapter` 增加 `authorNote` 参数；非空时在「本章大纲」之后注入【作者有话说（最高优先级）】块，声明与其他指示冲突时以作者为准（开篇衔接、完整收尾两条底线除外）；截断上限 `AUTHOR_NOTE_MAX_CHARS=500`。
- 前端 `NovelOutlinesTab.tsx`：
  - 新增「生成正文设置」弹窗（WriteTarget: 单章 one/one+append 或 all），含覆盖警告 Alert + 「作者有话说」TextArea（maxLength 500，保留上次输入便于多章复用）。
  - 原两条 Modal.confirm 覆盖确认（单章重写、一键全部）合并进该弹窗；「更多 → 生成正文/整章重写」「接着写」「一键生成正文」均先过此弹窗。
  - `writeOne(item, append, note)` / `writeAll(note)` 请求体带 `authorNote`（空则 undefined）。
- 验证：javac 增量编译通过并同步 backend/target/classes；RunTests 71/71 通过；前端 tsc + vite build 通过。
