## 覆盖确认框点确认后不关闭，压在生成弹窗上方
现象：章节大纲点「生成正文」→ 弹「覆盖确认」→ 点「覆盖生成」后，确认框不消失，
仍叠在正文生成弹窗之上（截图所示）。

根因：`Modal.confirm` 是静态命令式弹窗，`onOk` 返回 undefined 时 antd 会认为"处理完成"
并自动关闭；但这里 onOk 触发了 writeOne（异步流式、秒级不返回 promise），
实际问题是**它确实是异步边界**，导致关闭动画与新弹窗打开时序叠加，视觉上像没关。
根本修法：持有 confirm 返回的实例，在 onOk 里显式 `inst.destroy()` 后再打开生成弹窗，
保证先销毁提示、再打开生成窗口，不依赖 antd 的自动关闭时序。

### 改动（NovelOutlinesTab.tsx）
- `confirmWrite`：`const inst = Modal.confirm({... onOk: () => { inst.destroy(); writeOne(item); } })`，
  补 cancelText="取消"、maskClosable=true
- `confirmWriteAll`：同样处理，`onOk: () => { inst.destroy(); void writeAll(); }`
- 删除确认框（删除大纲）未改：其后不再开弹窗，antd 自动关闭正常

**经验**：命令式 Modal.confirm 若在 onOk 里立即打开另一个 Modal，
务必 `inst.destroy()` 显式销毁，否则会出现两个弹窗叠加的视觉 bug。

验证：前端 npm run build 通过。
